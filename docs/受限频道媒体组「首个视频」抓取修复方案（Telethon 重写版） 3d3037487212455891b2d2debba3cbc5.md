# 受限频道媒体组「首个视频」抓取修复方案（Telethon 重写版）

<aside>
📌

本文档针对项目 **Save-restricted-content-telegram-bot** 中「私密不可转发频道 → 媒体组 → 首个文件（视频）提取不到」的问题，给出根因分析与完整重写代码（纯 Telethon 方案）。

</aside>

## 一、问题结论

「首个视频取不到」不是单点 bug，而是三层问题叠加：

1. **架构层**：Telethon 迁移不彻底，`pbatch.py` 仍是 Pyrogram 写法，全靠兼容层 `TelethonUserClient` 硬撑。
2. **相册语义层**：相册的「第一条」恰好是 caption 载体，最容易以 shell / `MessageMediaUnsupported` 形式返回。
3. **代码逻辑层**：回退逻辑对「解析不出媒体的首条」是**直接 `continue` 跳过**，且用同一个失败方法去 refetch，所以首条永远补不回来。

---

## 二、根因逐条分析

### 根因 1：`MessageMediaUnsupported` 被误判为「无媒体」

兼容层里这行是关键：

```python
self.media = raw_msg.media is not None and not isinstance(raw_msg.media, MessageMediaUnsupported)
```

只要首条返回 `MessageMediaUnsupported`，`self.media=False`、`self.video=False`，这条消息就被判定成「没有媒体的壳消息」。而相册里带 caption 的往往就是**第一条**，于是首个视频稳定掉进 shell 分支。

### 根因 2：回退逻辑主动丢弃首条（最致命）

`get_media_group()` 回退里：

```python
if not _gm_has_media and _gm.media:
    _refetched = await user_client.get_messages(...)   # 用同一个失败方法
if not _gm_has_media:
    LOGGER.info("...has no media, skipping")
    continue                                            # ← 首条被直接跳过
```

- refetch 用的是**同样会返回 shell 的方法**，补不回来；
- 补不回来就 `continue` 跳过。
- 结果：相册里其它有正常媒体属性的成员能下，唯独作为 caption 载体的**首个视频被永久丢弃**。

### 根因 3：相册成员判定用「±50 扫描 + 手工拼」，不可靠

兼容层 `_get_media_group()` 用 `offset_id ± 50` 的历史/搜索接口去拼相册，边界消息（尤其首条）容易漏，且它返回的首条同样可能是 shell —— 等于用一个坏结果去补另一个坏结果。相册成员的**消息 ID 是连续的**，应改为按连续 ID 一次性批量取。

### 根因 4：参数名不一致导致下载被静默吞掉

调用处用 Pyrogram 风格 `progress_args=`，而兼容层 `download` 只接受 `progressArgs=`（驼峰），不一致时会抛 `TypeError` 并被外层 `except` 静默捕获，表现同样是「下不下来」。

---

## 三、修复思路

<aside>
✅

四个核心改动

</aside>

1. **不再跳过 shell**：`MessageMediaUnsupported` 或无媒体成员，改用 raw API（`ChannelsGetMessages`）重新获取，而不是 `continue`。
2. **相册按连续 ID 一次性批量取**：废弃 ±50 扫描，用 `get_messages(ids=[range])`。
3. **处理 file reference 失效**：捕获 `FileReferenceExpired` / `FileIdInvalid`，刷新后重下。
4. **统一参数名**：全部使用 `progressArgs`。

---

## 四、完整文件：`utils/telethon_client.py`（重写版）

```python
"""
TelethonUserClient — Telethon 原生封装
- 插件 (pbatch.py) 仍调用原有的 Pyrofork 兼容接口，但内部使用 Telethon 原生 API，
  重点解决「相册首个文件（shell 消息）」丢失问题。
- 使用 Android 设备模拟 (SM-S9180 / Android 13 / app 10.14.0) 获取受限频道内容。

设计原则:
  1. 废弃旧的 _get_media_group ±50 扫描。相册成员 ID 连续，改用
     get_messages(ids=[range]) 一次性批量获取。
  2. 将 MessageMediaUnsupported 视为「获取失败」而非「无媒体」，
     用 raw API (ChannelsGetMessages) 重新获取并保存到 _refreshed_raw。
  3. download_media 捕获 FileReferenceExpired / FileIdInvalid，刷新后重试。
  4. 保留 Pyrofork 兼容的 raw.functions / raw.types，内部自动转换为 Telethon 请求。
"""

import os
import logging
from typing import Optional, AsyncGenerator

LOGGER = logging.getLogger(__name__)

from telethon import TelegramClient
from telethon.sessions import StringSession
from telethon.tl.types import (
    MessageMediaPhoto,
    MessageMediaDocument,
    MessageMediaUnsupported,
    DocumentAttributeVideo,
    DocumentAttributeAudio,
    DocumentAttributeAnimated,
    DocumentAttributeSticker,
    InputPeerSelf,
    PeerChannel, PeerChat, PeerUser,
    InputMessageID,
)
from telethon.tl.functions.channels import (
    GetChannelsRequest,
    GetMessagesRequest as ChannelsGetMessagesRequest,
)
from telethon.tl.functions.messages import ForwardMessagesRequest
from telethon.errors import (
    ChatForwardsRestrictedError,
    FileReferenceExpiredError,
    FileIdInvalidError,
)
try:
    from telethon.errors import FileReferenceEmptyError
    _REF_ERRORS = (FileReferenceExpiredError, FileIdInvalidError, FileReferenceEmptyError)
except ImportError:
    _REF_ERRORS = (FileReferenceExpiredError, FileIdInvalidError)

# ══════════════════════════════════════════════════════════════════
# 媒体类型判定辅助
# ══════════════════════════════════════════════════════════════════

def _is_photo(media) -> bool:
    return isinstance(media, MessageMediaPhoto)

def _is_document_any(media) -> bool:
    return isinstance(media, MessageMediaDocument)

def _is_video(media) -> bool:
    if not isinstance(media, MessageMediaDocument):
        return False
    for attr in getattr(media.document, "attributes", []):
        if isinstance(attr, DocumentAttributeVideo) and not getattr(attr, "round_message", False):
            return True
    return False

def _is_audio(media) -> bool:
    if not isinstance(media, MessageMediaDocument):
        return False
    for attr in getattr(media.document, "attributes", []):
        if isinstance(attr, DocumentAttributeAudio) and not getattr(attr, "voice", False):
            return True
    return False

def _is_voice(media) -> bool:
    if not isinstance(media, MessageMediaDocument):
        return False
    for attr in getattr(media.document, "attributes", []):
        if isinstance(attr, DocumentAttributeAudio) and getattr(attr, "voice", False):
            return True
    return False

def _is_video_note(media) -> bool:
    if not isinstance(media, MessageMediaDocument):
        return False
    for attr in getattr(media.document, "attributes", []):
        if isinstance(attr, DocumentAttributeVideo) and getattr(attr, "round_message", False):
            return True
    return False

def _is_animation(media) -> bool:
    if not isinstance(media, MessageMediaDocument):
        return False
    for attr in getattr(media.document, "attributes", []):
        if isinstance(attr, DocumentAttributeAnimated):
            return True
    return False

def _is_sticker(media) -> bool:
    if not isinstance(media, MessageMediaDocument):
        return False
    for attr in getattr(media.document, "attributes", []):
        if isinstance(attr, DocumentAttributeSticker):
            return True
    return False

# ══════════════════════════════════════════════════════════════════
# 消息封装
# ══════════════════════════════════════════════════════════════════

class TelethonMessage:
    """将 Telethon Message 封装为 Pyrofork 兼容属性。"""

    def __init__(self, raw_msg, client: "TelethonUserClient", refreshed: bool = False):
        self._raw = raw_msg
        self._client = client
        self.id = raw_msg.id
        self.empty = False

        # 未支持 / 无媒体判定
        _unsup = (raw_msg.media is None or isinstance(raw_msg.media, MessageMediaUnsupported))
        self._unsupported = _unsup

        # 媒体标志 (Pyrofork 兼容)
        self.media = (raw_msg.media is not None and not _unsup)
        self._media = raw_msg.media

        self.video = _is_video(raw_msg.media) if not _unsup else False
        self.photo = _is_photo(raw_msg.media) if not _unsup else False
        self.document = _is_document_any(raw_msg.media) if not _unsup else False
        self.audio = _is_audio(raw_msg.media) if not _unsup else False
        self.voice = _is_voice(raw_msg.media) if not _unsup else False
        self.video_note = _is_video_note(raw_msg.media) if not _unsup else False
        self.animation = _is_animation(raw_msg.media) if not _unsup else False
        self.sticker = _is_sticker(raw_msg.media) if not _unsup else False

        # media_group_id (Pyrofork 命名)
        self.media_group_id = getattr(raw_msg, "grouped_id", None)
        self.grouped_id = self.media_group_id

        self.text = raw_msg.message or ""
        self.caption = raw_msg.message or ""
        self.caption_entities = getattr(raw_msg, "entities", None)

        # 转发信息
        self.forward_from_chat = None
        self.forward_from_message_id = None
        fwd = getattr(raw_msg, "fwd_from", None)
        if fwd:
            from_id = getattr(fwd, "from_id", None)
            if from_id and getattr(from_id, "channel_id", None):
                self.forward_from_chat = type("obj", (object,), {"id": from_id.channel_id})()
                self.forward_from_message_id = getattr(fwd, "channel_post", None)

        # ⚡ 已刷新的原始消息 (未支持时通过 raw API 补充)
        self._refreshed_raw = raw_msg if not _unsup else None

    async def ensure_refreshed(self):
        """对未支持 / 无媒体的消息，通过 raw API 重新获取。"""
        if self._refreshed_raw is not None:
            return self._refreshed_raw
        try:
            self._refreshed_raw = await self._client._refresh_raw(self._raw)
            if self._refreshed_raw is not None:
                _unsup = (self._refreshed_raw.media is None or
                          isinstance(self._refreshed_raw.media, MessageMediaUnsupported))
                self._raw = self._refreshed_raw
                if not _unsup:
                    self._unsupported = False
                    self._media = self._refreshed_raw.media
                    self.media = True
                    self.video = _is_video(self._media)
                    self.photo = _is_photo(self._media)
                    self.document = _is_document_any(self._media)
                    self.audio = _is_audio(self._media)
                    self.voice = _is_voice(self._media)
                    self.video_note = _is_video_note(self._media)
                    self.animation = _is_animation(self._media)
                    self.sticker = _is_sticker(self._media)
                    return self._refreshed_raw
                LOGGER.warning(
                    f"[TelethonMessage] id={self.id} 刷新后仍为 unsupported —— "
                    f"疑似非频道成员或 layer 兼容性问题"
                )
        except Exception as e:
            LOGGER.warning(f"[TelethonMessage] ensure_refreshed 失败 id={self.id}: {e}")
        return self._refreshed_raw

    async def download(self, file_name: str = None, progress=None, progressArgs=None):
        return await self._client.download_media(
            self._raw, file_name=file_name, progress=progress, progressArgs=progressArgs
        )

    async def get_media_group(self):
        return await self._client._get_media_group(self._raw)

# ══════════════════════════════════════════════════════════════════
# 客户端封装
# ══════════════════════════════════════════════════════════════════

class TelethonUserClient:
    """Telethon 封装器，提供 Pyrofork 兼容方法。"""

    def __init__(self, session_string: str, api_id: int, api_hash: str):
        self._session = session_string
        self._api_id = api_id
        self._api_hash = api_hash
        self._client: Optional[TelegramClient] = None
        self.peers_by_id = {}   # Pyrofork 兼容
        self._peer_cache = {}
        self._entity_cache = {}

    async def start(self):
        self._client = TelegramClient(
            StringSession(self._session),
            self._api_id,
            self._api_hash,
            device_model="SM-S9180",
            system_version="Android 13",
            app_version="10.14.0",
            lang_code="zh",
            system_lang_code="zh-CN",
        )
        await self._client.connect()
        if not await self._client.is_user_authorized():
            raise RuntimeError("Telethon session not authorized")
        LOGGER.info("[TelethonClient] 已连接 (Android 设备模拟)")
        return self

    async def disconnect(self):
        if self._client:
            await self._client.disconnect()

    async def stop(self):
        await self.disconnect()

    async def __aenter__(self):
        return await self.start()

    async def __aexit__(self, *args):
        await self.disconnect()

    # ── Peer / Entity 解析 ──
    async def _get_entity_cached(self, chat_id):
        try:
            if chat_id in self._entity_cache:
                return self._entity_cache[chat_id]
            entity = await self._client.get_entity(chat_id)
            self._entity_cache[chat_id] = entity
            return entity
        except Exception as e:
            LOGGER.warning(f"[TelethonClient] get_entity 失败 {chat_id}: {e}")
            return None

    async def resolve_peer(self, chat_id):
        try:
            entity = await self._get_entity_cached(chat_id)
            if entity is None:
                raise ValueError(f"无法解析 {chat_id}")
            if hasattr(entity, "access_hash"):
                self.peers_by_id[chat_id] = type("obj", (object,), {
                    "access_hash": entity.access_hash,
                    "channel_id": getattr(entity, "id", 0),
                })()
                self._peer_cache[chat_id] = entity
            return entity
        except Exception as e:
            LOGGER.warning(f"[TelethonClient] resolve_peer 失败 {chat_id}: {e}")
            raise

    async def _get_cached_entity(self, chat_id):
        return self._peer_cache.get(chat_id) or await self._get_entity_cached(chat_id)

    # ── ⚡ 未支持 / shell 消息的 raw 重新获取 ──
    async def _refresh_raw(self, raw_msg):
        """
        通过 ChannelsGetMessages 重新获取 MessageMediaUnsupported 或无媒体消息。
        相册「首条」容易 shell 化，但 raw API 通常能取到真实媒体。
        """
        try:
            peer_id = getattr(raw_msg, "peer_id", None)
            if not peer_id:
                return None
            if isinstance(peer_id, PeerChannel):
                entity = await self._get_entity_cached(int(f"-100{peer_id.channel_id}"))
            elif isinstance(peer_id, PeerChat):
                entity = await self._get_entity_cached(int(f"-{peer_id.chat_id}"))
            elif isinstance(peer_id, PeerUser):
                entity = await self._get_entity_cached(peer_id.user_id)
            else:
                return None
            if entity is None:
                return None
            res = await self._client(ChannelsGetMessagesRequest(
                channel=entity,
                id=[InputMessageID(id=raw_msg.id)],
            ))
            msgs = getattr(res, "messages", [])
            if msgs:
                return msgs[0]
        except Exception as e:
            LOGGER.warning(f"[TelethonClient] _refresh_raw 失败 id={getattr(raw_msg, 'id', '?')}: {e}")
        return None

    # ── 消息获取 ──
    async def get_chat_history(
        self, chat_id, offset_id: int = 0, limit: int = 100
    ) -> AsyncGenerator[TelethonMessage, None]:
        try:
            entity = await self._get_cached_entity(chat_id)
            if not entity:
                entity = await self._client.get_entity(chat_id)
            messages = await self._client.get_messages(entity, limit=limit, offset_id=offset_id)
            if messages:
                for msg in messages:
                    if msg:
                        yield TelethonMessage(msg, self)
        except Exception as e:
            LOGGER.warning(f"[TelethonClient] get_chat_history 失败: {e}")

    async def get_messages(self, chat_id, message_ids):
        try:
            entity = await self._get_cached_entity(chat_id)
            if not entity:
                entity = await self._client.get_entity(chat_id)
            msgs = await self._client.get_messages(entity, ids=message_ids)
            if not msgs:
                return []
            if not isinstance(msgs, list):
                msgs = [msgs]
            return [TelethonMessage(m, self) for m in msgs if m]
        except Exception as e:
            LOGGER.warning(f"[TelethonClient] get_messages 失败: {e}")
            return []

    # ── ⚡ 相册获取 (连续 ID 一次性批量) ──
    async def _get_media_group(self, raw_msg):
        """
        获取指定消息所属相册的全部成员。

        旧实现问题: ±50 扫描容易漏掉边界消息(尤其首条)，是首个文件丢失的直接原因。
        新实现: 相册成员 ID 连续 → get_messages(ids=[range]) 一次性批量取，
                再按 grouped_id 过滤排序; 对 unsupported 成员逐个 _refresh_raw。
        """
        ALBUM_MAX = 12  # Telegram 相册上限 10，留缓冲
        grouped_id = getattr(raw_msg, "grouped_id", None)
        if not grouped_id:
            return [TelethonMessage(raw_msg, self)]

        try:
            peer_id = getattr(raw_msg, "peer_id", None)
            if not peer_id:
                return []
            if isinstance(peer_id, PeerChannel):
                entity = await self._get_entity_cached(int(f"-100{peer_id.channel_id}"))
            elif isinstance(peer_id, PeerChat):
                entity = await self._get_entity_cached(int(f"-{peer_id.chat_id}"))
            elif isinstance(peer_id, PeerUser):
                entity = await self._get_entity_cached(peer_id.user_id)
            else:
                return []
            if entity is None:
                return []

            center = raw_msg.id
            ids = list(range(max(1, center - ALBUM_MAX), center + ALBUM_MAX + 1))
            msgs = await self._client.get_messages(entity, ids=ids)
            if not msgs:
                return [TelethonMessage(raw_msg, self)]
            if not isinstance(msgs, list):
                msgs = [msgs]

            group = [m for m in msgs if m and getattr(m, "grouped_id", None) == grouped_id]
            if not any(m.id == raw_msg.id for m in group):
                group.append(raw_msg)
            group.sort(key=lambda m: m.id)

            result = []
            for m in group:
                tm = TelethonMessage(m, self)
                if tm._unsupported or tm.media is False:
                    refreshed = await tm.ensure_refreshed()
                    if refreshed is not None:
                        tm = TelethonMessage(refreshed, self, refreshed=True)
                result.append(tm)
            LOGGER.info(
                f"[TelethonClient] _get_media_group grouped_id={grouped_id} "
                f"成员数={len(result)} ids={[m.id for m in result]} "
                f"unsupported={[m.id for m in result if m._unsupported]}"
            )
            return result
        except Exception as e:
            LOGGER.warning(f"[TelethonClient] _get_media_group 失败: {e}")
            return [TelethonMessage(raw_msg, self)]

    # ── download_media (支持 file reference 刷新) ──
    async def download_media(
        self, message, file_name: str = None, progress=None, progressArgs=None
    ):
        raw_msg = message._raw if isinstance(message, TelethonMessage) else message
        entity = None
        try:
            peer_id = getattr(raw_msg, "peer_id", None)
            if peer_id is not None:
                if isinstance(peer_id, PeerChannel):
                    entity = await self._get_entity_cached(int(f"-100{peer_id.channel_id}"))
                elif isinstance(peer_id, PeerChat):
                    entity = await self._get_entity_cached(int(f"-{peer_id.chat_id}"))
                elif isinstance(peer_id, PeerUser):
                    entity = await self._get_entity_cached(peer_id.user_id)
        except Exception:
            entity = None

        cb = self._make_progress(progress, progressArgs) if progress else None
        try:
            return await self._client.download_media(raw_msg, file=file_name, progress_callback=cb)
        except _REF_ERRORS as e:
            LOGGER.info(f"[TelethonClient] file reference 失效 (id={getattr(raw_msg,'id','?')}): {type(e).__name__}，刷新后重试")
            try:
                if entity is not None:
                    refreshed = await self._client(ChannelsGetMessagesRequest(
                        channel=entity,
                        id=[InputMessageID(id=raw_msg.id)],
                    ))
                    new_msgs = getattr(refreshed, "messages", [])
                    if new_msgs:
                        new_raw = new_msgs[0]
                        if isinstance(message, TelethonMessage):
                            message._raw = new_raw
                            message._refreshed_raw = new_raw
                        return await self._client.download_media(
                            new_raw, file=file_name, progress_callback=cb
                        )
            except Exception as re_err:
                LOGGER.warning(f"[TelethonClient] 刷新后重试仍失败: {re_err}")
            raise

    def _make_progress(self, progress_callback, progress_args):
        async def wrapper(current, total):
            if progress_callback and progress_args is not None:
                await progress_callback(current, total, *progress_args)
            elif progress_callback:
                await progress_callback(current, total)
        return wrapper

    # ── 上传 ──
    async def send_file(self, *args, **kwargs):
        return await self._client.send_file(*args, **kwargs)

    async def send_video(self, chat_id, file_path, caption="", duration=0,
                         width=0, height=0, thumb=None, supports_streaming=True,
                         parse_mode=None):
        kwargs = dict(caption=caption, duration=duration, width=width, height=height,
                      supports_streaming=supports_streaming)
        if thumb and isinstance(thumb, str) and os.path.exists(thumb):
            kwargs["thumb"] = thumb
        return await self._client.send_file(chat_id, file_path, **kwargs)

    async def send_photo(self, chat_id, file_path, caption="", parse_mode=None):
        return await self._client.send_file(chat_id, file_path, caption=caption)

    async def send_document(self, chat_id, file_path, caption="", thumb=None, parse_mode=None):
        kwargs = dict(caption=caption, force_document=True)
        if thumb and isinstance(thumb, str) and os.path.exists(thumb):
            kwargs["thumb"] = thumb
        return await self._client.send_file(chat_id, file_path, **kwargs)

    async def send_audio(self, chat_id, file_path, caption="", duration=0,
                         performer=None, title=None, thumb=None):
        kwargs = dict(caption=caption, duration=duration)
        if performer:
            kwargs["performer"] = performer
        if title:
            kwargs["title"] = title
        if thumb:
            kwargs["thumb"] = thumb
        return await self._client.send_file(chat_id, file_path, **kwargs)

    async def send_video_note(self, chat_id, file_path, duration=0, thumb=None):
        return await self._client.send_file(chat_id, file_path, video_note=True, duration=duration)

    async def send_voice(self, chat_id, file_path, caption="", duration=0):
        kwargs = dict(voice_note=True, caption=caption)
        if duration:
            kwargs["duration"] = duration
        return await self._client.send_file(chat_id, file_path, **kwargs)

    async def send_message(self, chat_id, text, parse_mode=None, reply_to_message_id=None):
        return await self._client.send_message(chat_id, text, parse_mode=parse_mode,
                                               reply_to=reply_to_message_id)

    # ── 转发 / 复制 ──
    async def forward_messages(self, chat_id, from_chat_id, message_ids):
        try:
            entity = await self._get_cached_entity(from_chat_id)
            if not entity:
                entity = await self._client.get_entity(from_chat_id)
            return await self._client.forward_messages(chat_id, message_ids, entity)
        except ChatForwardsRestrictedError:
            raise
        except Exception as e:
            LOGGER.warning(f"[TelethonClient] forward_messages 失败: {e}")
            raise

    async def copy_message(self, chat_id, from_chat_id, message_id):
        try:
            entity = await self._get_cached_entity(from_chat_id)
            if not entity:
                entity = await self._client.get_entity(from_chat_id)
            msg = await self._client.get_messages(entity, ids=message_id)
            if msg:
                return await self._client.send_message(chat_id, msg.message or "")
        except Exception as e:
            LOGGER.warning(f"[TelethonClient] copy_message 失败: {e}")
            raise

    # ── raw API 兼容层 ──
    @property
    def raw(self):
        return self._RawCompat(self)

    class _RawCompat:
        def __init__(self, client):
            self._client = client

    async def invoke(self, func):
        """将 Pyrofork raw API 自动翻译为 Telethon。"""
        from telethon.tl.functions.channels import GetChannelsRequest, GetMessagesRequest as CGM
        from telethon.tl.functions.messages import ForwardMessagesRequest

        cls = type(func).__name__
        module = getattr(type(func), "__module__", "")
        if "pyrogram" in module or "pyrofork" in module:
            if cls == "GetChannels":
                telethon_func = GetChannelsRequest(
                    id=[getattr(i, "channel_id", getattr(i, "id", 0)) for i in func.id]
                )
            elif cls == "GetMessages":
                telethon_func = CGM(channel=func.channel, id=func.id)
            elif cls == "ForwardMessages":
                telethon_func = ForwardMessagesRequest(
                    from_peer=func.from_peer, id=func.id, to_peer=func.to_peer,
                    random_id=func.random_id, noforwards=getattr(func, "noforwards", False),
                )
            else:
                LOGGER.warning(f"[TelethonClient] 未知 Pyrofork 函数: {cls}，透传")
                telethon_func = func
        else:
            telethon_func = func
        return await self._client(telethon_func)
```

把 `pbatch.py` 里「方法0/方法1：`get_media_group()`」循环内这段：

替换为下面的逻辑（**先 raw 刷新，再下载，不再 `continue` 丢弃**）：

```python
# 媒体未取到的成员：不再跳过，改为 raw API 刷新 → 下载
if not _gm_has_media:
    LOGGER.info(f"[v21] 成员 {_gm_id} 无媒体，尝试 raw 刷新后下载")
    refreshed_raw = None
    try:
        refreshed_raw = await user_client._refresh_raw(_gm._raw)
    except Exception as refresh_err:
        LOGGER.warning(f"[v21] raw 刷新失败 {_gm_id}: {refresh_err}")
    if refreshed_raw is not None:
        try:
            _gm_dl_name = _build_dl_filename(_gm, _gm_id,
                                             getattr(refreshed_raw, 'media', None) or _gm.media)
            _gm_path = await user_client.download_media(
                refreshed_raw,
                file_name=_gm_dl_name,
                progress=Leaves.progress_for_pyrogram,
                progressArgs=progressArgs("downloading", status_message, start_ts),
            )
            if _gm_path and os.path.exists(_gm_path):
                _gm_ext = os.path.splitext(_gm_path)[1].lower()
                _gm_type = (
                    MessageMediaType.VIDEO if _gm_ext in ('.mp4','.mkv','.webm','.mov','.avi')
                    else MessageMediaType.PHOTO if _gm_ext in ('.jpg','.jpeg','.png','.webp','.gif')
                    else MessageMediaType.DOCUMENT
                )
                _gm_cap = await get_parsed_msg(_gm.caption or "", _gm.caption_entities or [])
                await _upload_to_saved(user_client, _gm_type, _gm_path, _gm_cap, thumbnail_path, _gm_id)
                _group_success += 1
                LOGGER.info(f"[v21] raw 刷新下载成功: 成员 {_gm_id} type={_gm_type}")
                try: os.remove(_gm_path)
                except: pass
                continue   # ✅ 成功，处理下一个成员
            else:
                LOGGER.warning(f"[v21] raw 刷新下载为空 {_gm_id}")
        except Exception as raw_dl_err:
            LOGGER.warning(f"[v21] raw 刷新下载出错 {_gm_id}: {raw_dl_err}")
    # 到这里说明 raw 刷新也没成功 —— 落到下面统一下载分支再试一次，仍不 continue

# 统一下载分支 (注意: 参数名统一为 progressArgs)
try:
    _gm_dl_name = _build_dl_filename(_gm, _gm_id, _gm.media)
    _gm_path = await _gm.download(
        file_name=_gm_dl_name,
        progress=Leaves.progress_for_pyrogram,
        progressArgs=progressArgs("downloading", status_message, start_ts),
    )
    if _gm_path and os.path.exists(_gm_path):
        _gm_ext = os.path.splitext(_gm_path)[1].lower()
        _gm_type = (
            MessageMediaType.VIDEO if _gm.video or _gm_ext in ('.mp4','.mkv','.webm','.mov','.avi')
            else MessageMediaType.PHOTO if _gm.photo or _gm_ext in ('.jpg','.jpeg','.png','.webp','.gif')
            else MessageMediaType.AUDIO if _gm.audio or _gm_ext in ('.mp3','.m4a','.wav','.flac')
            else MessageMediaType.DOCUMENT
        )
        _gm_cap = await get_parsed_msg(_gm.caption or "", _gm.caption_entities or [])
        await _upload_to_saved(user_client, _gm_type, _gm_path, _gm_cap, thumbnail_path, _gm_id)
        _group_success += 1
        LOGGER.info(f"[v21] get_media_group 下载成功: 成员 {_gm_id} type={_gm_type}")
        try: os.remove(_gm_path)
        except: pass
    else:
        LOGGER.warning(f"[v21] get_media_group 下载失败 {_gm_id}")
except Exception as _gm_err:
    LOGGER.warning(f"[v21] get_media_group 出错 {_gm_id}: {_gm_err}")
```
